Sleutels voor pushmeldingen

Deze pagina maakt de sleutels voor pushmeldingen. Alles gebeurt op je eigen telefoon of computer; er wordt niets verstuurd. Je hebt dit maar één keer nodig.

1. VAPID_PUBLIC_KEY (openbaar)
Komt in Edge Functions → Secrets én in de SQL hieronder.
2. VAPID_PRIVATE_KEY (geheim)
Alleen in Edge Functions → Secrets. Nergens anders plakken.
3. PUSH_WEBHOOK_SECRET (geheim)
In Edge Functions → Secrets én als header x-webhook-secret in de Database Webhook.
4. SQL (in de SQL Editor draaien)

Bewaar deze waarden tot je klaar bent en sluit daarna de pagina. Ververs je de pagina, dan krijg je nieuwe sleutels.
